Código de Integración Hitbase (Cliente HTML/JS)

Inserta esta configuración en cualquier archivo `.html` para habilitar el SDK de Hitbase en tu aplicación sin exponer credenciales externas:

<!-- Hitbase Engine v2 CDN -->
<script src="https://cdn.makebyr.github.io/hit.base/v2/hitbase.js"></script>
<script>
  Hitbase.initializeApp({
      apiKey: "HTB-6I0HYBL",
      serverDomain: "hit./HTB-6I0HYBL"
  });
</script>
